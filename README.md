# Stem

Complete saved **Stem 0.5.0** game project, including all source files, bundled assets, rules, tests, launchers and documentation.

## Play locally

Install Python 3.10 or newer. On Windows, open `stem` and double-click `Start-Windows.bat`. On Linux or macOS:

```sh
cd stem
python3 server.py
```

Open `http://localhost:8776` and keep the server running. See the [original project instructions](stem/README.md) for platform and multiplayer details.

## Included files

- [stem/](stem/): every file from `Stem-Prototype.zip`, preserved byte for byte.
- [docs/README.md](docs/README.md): indexed guides, audits and retained validation records.
- [docs/shared/](docs/shared/): printable character sheet, creature/stat guide and encounter toolkit.
- [upload-manifest.json](upload-manifest.json): source versions, coverage and file checksums.

Historical audits retain their original dates and verification limits. This upload preserves the saved implementation.
